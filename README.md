# Raspberry Pi Tabanlı Uzaktan Kontrollü Araç ve Kontrol Arayüzü

Bu proje, 4G modem üzerinden haberleşen, Raspberry Pi tabanlı otonom ve uzaktan kontrollü bir araç sistemi ile bu aracı kontrol eden Java tabanlı tablet arayüzünü içermektedir.

## 🚀 Özellikler
- **Java GUI Kontrolü:** Yönlendirme, far kontrolü, ekran/fotoğraf kaydı ve sesli iletişim.
- **Canlı Görüntü Aktarımı:** Kamera modülünden RTSP protokolü ile düşük gecikmeli görüntü akışı.
- **Lidar ile Çarpışma Önleme:** Belirli bir mesafede nesne algılandığında otonom olarak durma yazılımı.
- **Haberleşme:** 4G modem entegrasyonu ile geniş kapsama alanı.

## 🛠️ Kullanılan Teknolojiler
- **Yazılım:** Java (Arayüz), Python/C (Gömülü Sistem)
- **Donanım:** Raspberry Pi, Lidar Sensörü, 4G Modem
- **Protokoller:** RTSP, TCP/IP
